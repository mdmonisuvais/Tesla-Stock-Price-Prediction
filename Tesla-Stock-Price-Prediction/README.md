Tesla Stock Price Prediction using Deep Learning
Project Overview

This project predicts Tesla (TSLA) stock prices using Deep Learning models:

SimpleRNN
LSTM

The objective is to forecast future stock prices based on historical stock market data and compare the performance of both recurrent neural network architectures.
